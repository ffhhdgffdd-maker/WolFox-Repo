# WolFox Repo Source

Canonical application source:

https://repo.p3nd.fun/source.php

Website catalog:

https://repo.p3nd.fun/

The live source is maintained from the WolFox Repo dashboard. Applications shown in the client are read from its `apps` array and each downloadable release must use an authorized HTTPS APK URL.

The catalog is Android-only. Certificate, provisioning-profile, UDID, and IPA data are outside the store source and must not be published here.
